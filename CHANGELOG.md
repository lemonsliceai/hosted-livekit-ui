# Changelog

## v0.2.0

Optional `models` prop on `<LemonSliceCall>`: the video models offered, in dropdown order, with the first selected by default. Each entry is an id or `{ model, label?, description? }`; `description` is a subtitle under the row. Without the prop the dropdown offers Standard then Premium. A single entry hides the dropdown.

Optional `agentOverrides` on the room config, for accounts with early access to additional models.
